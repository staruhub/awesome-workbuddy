# 如何用好 WorkBuddy「知识库」功能

> 截至 2026-08。WorkBuddy 里常被统称「知识库」的其实不止一种能力，先分清再动手。

## 先分清四个概念

| 名称 | 是什么 | 谁用 | 怎么用 |
| --- | --- | --- | --- |
| **资料库（Library）** | 人和 Agent 共同管理的文件树：文档、产物、素材 | 个人与团队 | 侧边栏「资料库」；「添加到任务」读写 |
| **企业自定义 RAG 知识库** | 企业管理后台上传的私有检索库 | 企业账号 | 后台创建/索引；对话里 `@ Docs` 引用 |
| **官方预置知识库** | 平台预置的框架/云 API 等技术库 | 企业可开关 | 后台启用后纳入 RAG |
| **乐享 / 腾讯网盘知识库** | 通过连接器接入的外部知识源 | 已授权用户 | 连接器管理页配置；可用子功能开关 |

新手最常见的误区：把「资料库里的 MD」当成「RAG 知识库」。前者是可读写的工作文件；后者是检索增强上下文，回答时引用，不等于直接改源文件。

---

## 一、资料库：日常沉淀与协作

官方定位：解决「资料放哪、谁能找到、Agent 能不能用」。

### 能力一览

1. **内容管理**：个人文档与团队资料分区；零散文件进同一棵目录树；任务中读取与修改。
2. **多人多 Agent 协作**：团队空间与权限；MD 审阅与 AI 修订；HTML 协同编辑。
3. **轻量发布**：本地 HTML 发成在线链接；HTML + CSV 搭轻应用。

### 「AI 三件套」怎么分工

| 格式 | 适合放什么 |
| --- | --- |
| **MD** | 方案、纪要、SOP、说明文档 |
| **CSV** | 表格数据、清单、可统计素材 |
| **HTML** | 页面、看板、可预览演示 |

办公文档（PDF / Word / PPT / Excel）与图片音视频也可上传归档。

### 推荐工作闭环

1. 打开侧边栏 **资料库**，看到「我的文档」与「团队空间」。
2. 把任务产物存进资料库（会话里让 Agent 保存，或对产物分享/发布）。
3. 本地文件、网页剪藏也可直接入库。
4. 需要再加工时：选中空间或文档 → **添加到任务**。
5. 新成果再存回资料库，形成可累积底座。

### 使用建议

- 添加到任务时，优先选**目录或空间**，而不是逐个点文件——Agent 上下文更完整。
- 目录按「项目 → 阶段 → 任务」组织，长期更好维护。
- 需要多人协作的内容尽早进**团队空间**，少做后期搬运。
- Agent 改 MD 可审阅、可回退：接受后才写入正文。

## 二、企业 RAG 知识库：让回答贴合公司知识

适用：企业账号。管理员在企业管理后台维护；成员在客户端用 `@ Docs` 引用。

### 官方知识库 vs 自定义知识库

| 类型 | 说明 | 场景 |
| --- | --- | --- |
| 官方知识库 | 预置开源框架与技术规范（如 React、Vue、Spring、腾讯云 API 等） | 快速接入常用技术栈 |
| 自定义知识库 | 企业上传的私有文档与代码资产 | SOP、产品手册、内部 API、遗留代码 |

### 创建自定义知识库（管理员）

1. 进入企业管理后台 → **知识库管理** → 创建。
2. **上传数据**（可拖拽）：
   - 文档：`.md` / `.markdown` / `.docx` / `.pdf` 及常见代码文件，**单文件 ≤ 30 MB**。
   - 压缩包：`.zip` / `.tar` / `.tgz` / `.tar.gz` / `.gz` 等，**单包 ≤ 300 MB**。
3. **检索设置**（常见两项）：
   - **Top K**：返回片段数量；偏小更精、偏大更全。
   - **Score threshold（相关性阈值）**：过低易噪声，过高易漏检。
4. 等待索引完成 → **开启知识库**。

### 客户端怎么用

1. 企业账号登录 WorkBuddy。
2. 对话框输入 `@`，选择 **Docs**，打开知识库列表。
3. 勾选要引用的官方/自定义知识库后提问。

### 场景速查

| 场景 | 推荐做法 |
| --- | --- |
| 用某框架开发 | 启用对应官方知识库 |
| 查内部 API | 自定义库上传 API 文档 |
| 啃遗留代码 | 以离线代码库/压缩包导入 |
| 多技术栈 | 同时启用多个相关库，观察噪声再调阈值 |

## 三、乐享 / 腾讯网盘知识库

- 通过**连接器**接入腾讯乐享、腾讯网盘等，让 Agent 按指令检索团队文档或云盘内容。
- 更新日志中出现过「腾讯网盘知识库子功能开关」「乐享知识库个人版团队知识库导航」等能力——以当前客户端连接器页为准。
- 适合「知识已在乐享/网盘、不想再拷一份到 RAG」的团队；与自定义 RAG 可并存，但要分清权威来源，避免两套文档打架。

---

## 常见误区

1. **只上传不维护**：过期 SOP 比没有更危险，定期清理与重索引。
2. **把聊天记录当知识库**：应沉淀为 MD/资料库或正式 RAG 文档。
3. **阈值一次拉满**：先小样本提问，再调 Top K / Score。
4. **个人敏感文件丢进团队空间或企业库**：权限边界要先于效率。

## 和「项目」怎么配合

- **项目**：共享指令、技能、连接器与协作流程。
- **资料库 / 资产库**：放正在用的工作文件与产物。
- **企业 RAG**：放「回答时应检索的稳定知识」。

三者一起用时：项目管人与规范，资料库管过程文件，RAG 管标准答案来源。
