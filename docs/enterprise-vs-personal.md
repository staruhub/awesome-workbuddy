# WorkBuddy 企业版与个人版区别

> 价格、积分与席位口径来自官方定价页与《WorkBuddy Enterprise 购买指南》（文档更新时间约 2026-08）。活动加赠会变化，下单前请再对官网。

## 一句话定位

| | 个人版 | 企业版 |
| --- | --- | --- |
| 定位 | 单兵提效：自己买、自己用、自己管 | 组织协同 + 治理：公司买、统一管、团队共用 |
| 适合谁 | 个人创作者、自由职业、先试用的同学 | 3 人以上协作、要权限/审计/知识沉淀的团队 |

CodeBuddy 与 WorkBuddy **同一账号积分共享**，无需分别订阅。

## 个人版：体验 / 标准 / 高级 / 旗舰

2026-07-01 起，国内个人版从单一专业版扩展为「标准 / 高级 / 旗舰」三档付费体系（另加免费体验版）。

| 项目 | 体验版 | 标准版 | 高级版 | 旗舰版 |
| --- | --- | --- | --- | --- |
| 月付 | 免费 | 99 元/月 | 199 元/月 | 999 元/月 |
| 连续包月（约 7 折） | — | 70 元/月 | 140 元/月 | 700 元/月 |
| 基础积分 / 月 | 500 | 2,000 | 4,000 | 20,000 |
| 限时加赠 / 月 | — | 2,000 | 5,000 | 30,000 |
| 限时每月实得 | 500 | 4,000 | 9,000 | 50,000 |
| 自动任务 | 3 个（限免可达 99） | 15（限免 99） | 30（限免 99） | 99 |
| 创建项目数 | 5 个/人 | 10 | 15 | 20 |
| 项目成员数 | 3 人/项目（限免 5） | 5 | 8 | 10 |
| 个人助理数 | 3 个/人 | 5 | 8 | 10 |
| 适用场景 | 入门体验 | 日常轻量 | 高频多项目 | 高强度复杂项目 |

说明：

- 开通付费后，体验版 500 积分不再另行发放。
- 付费会员可在积分将尽时购买**个人加量包**（如 1,000 Credits / 50 元，约 1 个月有效；以产品内入口为准）。
- 年付 / 连续包年折扣见官方定价页。

## 企业版：旗舰（SaaS）/ 专享（专有云）/ 私有化

| 项目 | 企业旗舰版（SaaS） | 企业专享版（专有云） | 企业私有化版 |
| --- | --- | --- | --- |
| 面向 | 中小团队，快速上线 | 中大型，合规与隔离 | 金融政企、信创、数据不出域 |
| 部署 | 腾讯云共享 VPC，多租户逻辑隔离 | 腾讯云专享 VPC / 专属资源池 | 企业自有环境与算力 |
| 起购 | **1 席**起 | **100 席**起 | **约 300 席**起（询价） |
| 月付 | 198 元/人/月 | 316 元/人/月 | 售前咨询 |
| 年付 | 2,376 元/人/年 | 3,792 元/人/年 | 售前咨询 |
| 积分 | 含 2,000 Credits/人/月，团队共享；对话不限频 | 同左 | 视私有化方案 |
| 限时加赠 | 常见为再赠 2,000/人/月（活动期以公告为准） | 同左 | — |

企业版还可购**加量包**（有效期约 6 个月），例如 2,000 / 5,000 / 10,000 / 50,000 / 200,000 Credits 等阶梯；**自定义模型不消耗 Credits**（官方计费说明）。

### 企业版相对个人版多出来的能力

| 能力 | 说明 |
| --- | --- |
| 组织与席位 | 统一身份 / 组织架构、席位分配、成员授权 |
| 用量与成本 | 成员用量统计、额度上限、部门归集 |
| 知识与智能体治理 | 企业知识库、企业 Skill / 专家 / 智能体、企业模型配置 |
| 安全与审计 | 安全策略、审计日志；专享/私有化加强网络与租户隔离 |
| 开放能力 | OpenAPI；专享另有专属插件与专属服务实例 |
| 私有化增量 | 数据不出域、国产化显卡与内网部署等（需售前确认） |

产品页概括：旗舰版强调「注册即用 + 完整企业特性」；专享版强调「专属网络与实例」；私有化强调「全栈可控」。

## 六维对比（怎么选）

| 维度 | 个人版 | 企业版 |
| --- | --- | --- |
| 组织管理 | 独立账号 | 管理后台 + 席位 + 角色权限 |
| 资产归属 | 绑定个人账号，离职易带走 | 企业侧沉淀，便于留存与交接 |
| 知识治理 | 个人资料库 / 项目资产为主 | 可统一企业 RAG、Skill、专家与模型 |
| 成本可见 | 个人主页看自己的用量 | 组织级用量与配额 |
| 安全合规 | 个人账号与客户端安全能力 | 审计、策略；专享/私有化强化隔离 |
| 协作上限 | 受个人档位的项目数/成员数约束 | 按席位与企业策略扩展 |

价格直觉（活动价另计）：企业旗舰 **198 元/人/月** 与个人高级 **199 元/月**接近，但企业版多出治理与共享积分池——**3 人以上要一起用**，通常企业版更划算、也好管。

## 选型建议

1. **先个人试用**：体验版或标准版跑通自己的工作流（Skill、连接器、项目）。
2. **≥3 人协作、要统一知识与权限** → 优先企业旗舰版（1 席起购）。
3. **强合规、要专属 VPC / 租户隔离** → 专享版（100 席起）。
4. **数据必须不出域 / 信创** → 私有化，走售前。
5. **积分不够**：个人用加量包或升档；企业用共享池 + 企业加量包，并由管理员设成员上限，避免「一人耗光全队」。
