# 如何用好 WorkBuddy「项目」功能

> 基于官方文档与更新日志整理（截至 2026-08）。配额与价格以产品内/官方定价页为准。

## 项目是什么

WorkBuddy 的「项目」是团队协作空间，不是本地文件夹的别名。从 **5.0.0（2026-06-03）** 起，项目把「共享配置 + 任务会话 + 计划看板 + 资产库」捆在一起：

| 层级 | 作用 |
| --- | --- |
| **项目** | 共享指令、连接器、专家、技能与资料；成员新建任务时自动继承 |
| **任务** | 项目里的一次对话会话，支持分享、转交、多人协作 |

一句话：先把团队规范写进项目，再开任务干活，避免每人每次重复配置。

入口：客户端左侧导航 **项目** → 左上角 **新建项目**。

## 创建时先配好这五项

| 配置项 | 是否必填 | 建议 |
| --- | --- | --- |
| 项目名称 | 必填 | 用业务名，如「Q3 产品发布」「客服知识运营」 |
| 指令 | 可选但强烈建议 | 写清语气、输出格式、禁区（勿外泄客户数据等）；所有任务自动继承 |
| 连接器 | 可选 | 区分**公共授权**（团队共用账号）与**个人授权**（私人服务） |
| 技能（Skill） | 可选 | 只挂本项目会用到的 Skill，少即是多 |
| 专家 | 可选 | 挂领域专家/专家团，任务里可召唤 |

### 连接器授权模式（常见坑）

- **公共授权**：适合团队共享的腾讯文档、企微、邮箱等；协作任务里可用。
- **个人授权**：适合个人私有服务；**协作任务中不可用**。

开启多人协作前，先确认项目里已配好必要的公共授权连接器，否则工具调用会失败。

## 三种任务协同方式

| 模式 | 适用场景 | 注意 |
| --- | --- | --- |
| **分享** | 把结果给同事看、留存产物 | 适合交付物评审，不等于共同编辑会话 |
| **转交** | 你开了头，交给同事续做 | 关注待办日期等字段是否完整保留 |
| **多人协作** | 同任务实时协同、队列派发 | 仅公共授权连接器可用 |

5.3.11 起支持 **Teams 项目邀请链接免审直接加入**，适合内部分享链接快速拉人；对外仍建议走审批。

## 计划看板与项目动态

- **计划看板**：待办创建、状态流转、批量操作；**5.3.3** 起支持待办富文本、评论贴图与动态留言。
- **项目动态**：成员操作与待办变更的时间线，方便复盘「谁在什么时候改了什么」。

建议：把「要验收的事」放看板，把「和 AI 一起干的活」放任务，两者用待办/转交串起来，而不是全堆在一个超长对话里。

## 项目资产库怎么用

资产库是项目级网盘：上传文件、建文件夹、看版本历史，并在任务里直接引用。

推荐闭环：

1. 模板、SOP、参考资料先入库（保持最新版）。
2. 开任务时从资产库引用，而不是从聊天记录翻文件。
3. 任务产物再存回资产库或资料库，形成可复用底座。

## 最佳实践清单

1. **先写项目指令，再开第一个任务**——指令是团队协作的地基。
2. **按业务建项目，不按「临时对话」建项目**——临时事用普通任务即可。
3. **协作前检查公共授权连接器**——少踩「工具 NOT CONNECTED」类坑。
4. **资产库只放可复用资料**——草稿可留在任务产物区，定稿再入库。
5. **看板管进度，任务管执行**——避免用对话代替项目管理。
6. **邀请链接分内外**——内部可免审，外部谨慎。
